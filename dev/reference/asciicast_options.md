# Default options to set in the asciicast subprocess.

Default options to set in the asciicast subprocess.

## Usage

``` r
asciicast_options()
```

## Value

Named list.

## Examples

``` r
asciicast_options()
#> $cli.num_colors
#> [1] 256
#> 
#> $cli.dynamic
#> [1] TRUE
#> 
#> $cli.ansi
#> [1] TRUE
#> 
```
