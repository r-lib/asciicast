# Extract / create complete screen frames from an ascii cast

Extract / create complete screen frames from an ascii cast

## Usage

``` r
load_frames(cast, height = NA, width = NA)
```

## Arguments

- cast:

  aciicast object

- height:

  Number of rows. (`NA` for default.)

- width:

  Number of columns. (`NA` for default.)

## Value

`asciicast_frames` object.
